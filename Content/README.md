# 📖 Plugin/Content

The MentalCraft Content & Narrative Intelligence Engine. Provides high-precision worldbuilding, character psychology architecture, 15-beat plot outlines, sensory prose rendering, lore consistency linting, interactive `.ink` compilation, and omnichannel growth marketing frameworks.

## 📦 Architecture & Capabilities

```
Plugin/Content/
├── modules/
│   ├── story.ts         # 🪐 Fiction Worldbuilding, Character Arcs, 15 Beats, Sensory Prose, Lore Lint, Ink
│   └── marketing.ts     # 📢 PAS Copywriting, Omnichannel Adapters (X/Reddit/WeChat/Bilibili), Viral Hooks
├── core.ts              # Type definitions & command unions
├── operation.ts         # Sovereign execution dispatcher & summary formatter
├── mcp-server.ts        # Protocol MCP server (`mentalcraft-content`)
└── content.test.ts      # 100% automated test suite
```

## 🛠️ Actions Matrix

| Category | Action | Description |
|---|---|---|
| **Story** | `story_worldbuilding_forge` | Generates world laws, factions, resource constraints, and chronicle milestones. |
| **Story** | `story_character_arc_architect` | Designs Want vs Need psychology, fatal flaws, arc types, and dialogue voice fingerprints. |
| **Story** | `story_plot_beat_composer` | Constructs 15-beat Save the Cat narrative outlines with tension curves and midpoint shifts. |
| **Story** | `story_sensory_prose_render` | Applies multi-layered sensory immersion and "Show, Don't Tell" enhancement. |
| **Story** | `story_lore_consistency_linter` | Audits manuscripts for world rule violations and tracks unresolved foreshadowing clues. |
| **Story** | `story_interactive_ink_exporter` | Compiles branching narrative DAGs into standard Inkle Ink (`.ink`) scripts. |
| **Marketing** | `marketing_pas_copywriter` | Crafts targeted Problem-Agitate-Solve conversion copy decks across personas. |
| **Marketing** | `marketing_omnichannel_adapter` | Adapts core message across Twitter/X, Reddit/HN, WeChat, RedBook, Bilibili, and Product Hunt. |
| **Marketing** | `marketing_viral_hook_generator` | Generates 3-second attention hooks, curiosity gap angles, and high-converting CTAs. |
| **Marketing** | `marketing_campaign_playbook` | Generates 14-day product launch sprint roadmaps with phase deliverables and KPIs. |
