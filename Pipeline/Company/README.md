# Plugin/Company - Corporate Governance, Cap Table & Compliance Protocol Engine

Part of the MentalCraft FastMCP Protocol Network (`holar.company.v1`).

## Capabilities
- `company_entity_audit`: Validates dual-jurisdiction operating entities (Wyoming LLC parent and Shanghai subsidiaries).
- `company_cap_table_calc`: Models equity ownership, option pool allocations, and investor dilution.
- `company_ip_assignment_audit`: Verifies IP chain of custody across software repositories, patents, and trademarks.
- `company_compliance_check`: Tracks annual report filings, registered agent status, and tax standing.
